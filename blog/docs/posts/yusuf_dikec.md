# Yusuf Dikeç

If you see "install IDE 'fancyshit'" as a prerequisite to any coding tutorial, most likely this is a shitty coding tutorial. 
Vim, gedit, notepad - any of this is sufficient to write the code. IDE has very little to so with coding per se but in tutorials derails understanding of essential concepts.  I do not want automated project structure creation, automated imports, fucking tips. I want to learn why the structure is like that, where that method comes from, what are the dependencies.
