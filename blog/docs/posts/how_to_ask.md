# How to ask questions

Bookmark: <a href="http://catb.org/~esr/faqs/smart-questions.html" target="_blank">How To Ask Questions The Smart Way</a>

!!! quote "Before You Ask"

    Before asking a technical question by e-mail, or in a newsgroup, or on a website chat board, do the following:
    <ol>
    <li>Try to find an answer by searching the archives of the forum or mailing list you plan to post to.
    <li>Try to find an answer by searching the Web.
    <li>Try to find an answer by reading the manual.
    <li>Try to find an answer by reading a FAQ.
    <li>Try to find an answer by inspection or experimentation.
    <li>Try to find an answer by asking a skilled friend.
    <li>If you're a programmer, try to find an answer by reading the source code.
    </ol>
