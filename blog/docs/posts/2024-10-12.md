# Impatience

A great temptation to get the Mac, because it resonates like it "just works".
But it is not true first of all, and this approach encourages **sloppy mind**.  

Maybe the thing about sloppy mind should go as "first of all".
You want some new tech toy, but you don't want to make an effort to find the best one for you.  

What's the fun then? Unless you trying to find something to get the job done right now - take a time, do the effort.
Practice some **patience** and **thoroughness**.
